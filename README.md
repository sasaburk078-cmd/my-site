# my-site

Демо-одностраничник, созданный ИИ-агентом через GitHub API.

🔗 Живой сайт: https://sasaburk078-cmd.github.io/my-site/

## Что внутри

- `index.html` — единственная страница (стили и скрипт внутри, без зависимостей).
- Публикация через **GitHub Pages** (ветка `main`, корень).

## Как обновить

Открой `index.html`, отредактируй, закоммить — сайт обновится сам за ~1 минуту.
